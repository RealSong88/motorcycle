# Africa Twin CRF1000L (2017 MT) 임도 튜닝 프로젝트

순정 상태의 2017 아프리카트윈 MT 모델을 임도(오프로드) 주행에 최적화하기 위한 튜닝 계획.

## 베이스 차량 스펙

| 항목 | 스펙 |
|------|------|
| 모델 | Honda CRF1000L Africa Twin (2017) |
| 변속기 | 6단 수동 (MT) |
| 엔진 | 998cc 병렬 트윈 |
| 출력 | 약 95마력 |
| 공차중량 | 약 232kg (습중량) |
| 휠 | 프론트 21" / 리어 18" |
| 최저지상고 | 250mm |
| 서스펜션 | 도립포크(프론트) / 프로링크(리어) |
| 연료탱크 | 18.8L |

## 튜닝 우선순위

임도 주행 기준으로 가성비와 효과를 고려한 우선순위.

### Phase 1 - 필수 (안전 & 보호)
- 엔진 가드 / 스키드 플레이트
- 핸드가드
- 헤드라이트 가드
- 오프로드 타이어

### Phase 2 - 권장 (주행 성능)
- 서스펜션 세팅 또는 업그레이드
- 와이드 풋페그
- 사이드 스탠드 확장판
- 리어 브레이크 페달 확장

### Phase 3 - 선택 (편의 & 성능)
- 랠리 스크린 또는 스크린 제거
- 핸들바 라이저
- 경량 배기 (슬립온)
- 내비게이션 마운트

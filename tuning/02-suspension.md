# 서스펜션

2017 아프리카트윈 순정 서스펜션은 온/오프로드 범용 세팅. 임도 위주로 쓰려면 조정이 필요.

## 순정 서스펜션 스펙

| 항목 | 프론트 | 리어 |
|------|--------|------|
| 타입 | 45mm 도립포크 (HMAS) | 프로링크 모노쇼크 |
| 트래블 | 230mm | 220mm |
| 프리로드 조절 | 가능 | 가능 (유압식) |
| 컴프레션 댐핑 | 조절 가능 | 조절 불가 (순정) |
| 리바운드 댐핑 | 조절 불가 (순정) | 조절 가능 |

## Option A: 순정 서스펜션 세팅 최적화 (무료)

- [ ] 세팅 변경

임도용 순정 세팅 가이드.

**프론트 포크**
- 프리로드: 체중 + 장비 기준으로 새그 조절 (정적 새그 30~35mm 목표)
- 컴프레션: 순정 대비 2~3클릭 소프트하게 (돌/뿌리 흡수)

**리어 쇼크**
- 프리로드: 정적 새그 35~40mm 목표
- 리바운드: 순정 대비 1~2클릭 빠르게 (연속 충격 대응)

## Option B: 스프링 교체 (중간 단계)

- [ ] 구매
- [ ] 장착

체중에 맞는 스프링 레이트로 교체. 순정은 75~80kg 라이더 기준.

| 브랜드 | 예상 가격 | 비고 |
|--------|-----------|------|
| Hyperpro | 프론트 40~50만원 / 리어 50~60만원 | 체중별 맞춤 스프링 |
| Touratech | 프론트+리어 세트 80~120만원 | Expedition 세트 |

## Option C: 풀 서스펜션 업그레이드 (최상급)

- [ ] 구매
- [ ] 장착

| 브랜드 | 제품 | 예상 가격 | 비고 |
|--------|------|-----------|------|
| Ohlins | 프론트 카트리지 + 리어 쇼크 | 250~350만원 | 최고급 |
| Touratech Suspension | Extreme 세트 | 200~280만원 | 오프로드 특화 |
| YSS | 프론트+리어 | 100~150만원 | 가성비 |

선택 기준: 임도 수준에 따라 결정.
- 가벼운 임도(비포장 도로): Option A로 충분.
- 본격 임도(돌밭, 급경사): Option B 이상 권장.
- 하드 엔듀로급: Option C 필요.

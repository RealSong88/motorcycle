# 타이어

임도 튜닝에서 체감 효과가 가장 큰 항목. 순정 타이어(보통 Dunlop Trailmax 또는 유사)는 온로드 위주.

## 타이어 사이즈 (2017 Africa Twin)

| 위치 | 사이즈 |
|------|--------|
| 프론트 | 90/90-21 |
| 리어 | 150/70-18 |

## 타이어 유형별 비교

### 50/50 (온오프 반반)

도로 주행도 많이 하면서 임도도 가는 경우.

| 타이어 | 예상 가격 (앞+뒤) | 비고 |
|--------|-------------------|------|
| Mitas E-07+ | 25~30만원 | 가성비 최강, 임도 입문 추천 |
| Shinko 705 | 15~20만원 | 최저가, 성능 무난 |
| Continental TKC 70 | 30~35만원 | 온로드 성능 좋음 |
| Heidenau K60 Scout | 30~35만원 | 내구성 우수, 젖은 노면 강점 |

### 70/30 ~ 80/20 (오프로드 위주)

- [ ] 구매
- [ ] 장착

임도 위주 + 이동 구간 도로 정도.

| 타이어 | 예상 가격 (앞+뒤) | 비고 |
|--------|-------------------|------|
| Mitas E-07 Dakar | 25~30만원 | E-07+보다 블록 큼 |
| Motoz Tractionator GPS | 35~40만원 | 임도 그립 탁월 |
| Continental TKC 80 | 30~35만원 | 클래식 오프로드 타이어 |
| Pirelli Scorpion Rally STR | 35~40만원 | 밸런스 좋음 |
| Dunlop D908RR | 35~40만원 | 랠리 레이드용 |

### 90/10 이상 (풀 오프로드 / 노비)

도로 주행 최소화, 임도 극대화.

| 타이어 | 예상 가격 (앞+뒤) | 비고 |
|--------|-------------------|------|
| Mitas E-09 | 20~25만원 | 가성비 노비 |
| Pirelli Scorpion Rally | 40~45만원 | 랠리 검증 |
| Motoz Tractionator Adventure | 35~40만원 | 진흙/모래 강점 |

## 추천

임도 입문이라면 **Mitas E-07+** 또는 **Continental TKC 80**으로 시작.
도로 이동이 적고 임도 비중이 높다면 **Motoz Tractionator GPS** 또는 **Pirelli Scorpion Rally STR**.

## 튜브 vs 튜브리스

2017 아프리카트윈은 **튜브 타입 휠**. 튜브리스 전환은 별도 키트 필요.
- 튜브 교체 용이성을 위해 휴대용 타이어 레버 + 펑크 킷 휴대 권장.
- Tubliss 시스템 고려 가능 (튜브 없이 저압 주행 가능).
